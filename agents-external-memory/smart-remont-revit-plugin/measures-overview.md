# Замеры по модели — обзор алгоритмов

Документ для понимания **логики расчёта** без привязки к реализации.  
Техническое описание с деталями реализации: [measures.md](measures.md).

---

## Что это такое

«Замеры по коду» — это автоматический расчёт показателей по квартире **напрямую из 3D-модели Revit**: границы помещений, двери, окна, полы, стены. Данные **не** читаются из спецификаций (ведомостей), за одним исключением: фартук кухни может подтянуться из ведомости, если она есть в проекте.

Результат — таблица «помещение → набор замеров», которую можно отправить на backend.

---

## Общие правила

### Какие помещения участвуют

Берутся все помещения квартиры, у которых:

- задана рабочая **фаза** (предпочтительно «После монтажных работ»; если такой фазы нет — первая доступная);
- **площадь больше нуля**.

Помещения сортируются по номеру, затем по имени.

### Как понимаются имена

«Кухня №2», «Кухня (2)» и просто «Кухня» считаются **одним типом** помещения — «Кухня». То же для «Гостиная», «Прихожая» и т.д. Это нужно, чтобы правильно применять ограничения «только для кухни» и т.п.

### Единицы и точность

- длины — **метры** (м);
- площади — **квадратные метры** (м²);
- значения округляются до **сотых** (0,01).

### Когда замер пустой

Если для помещения замер не применим (например, двустворчатая дверь — только для гостиной) или получилось **ноль**, в таблице значение **не заполняется** (остаётся пустым).

## 1. Периметр по полу

**Зачем:** длина плинтуса по полу с учётом дверных проёмов.

**Как считается:**

1. Берётся **полный периметр** помещения по контуру отделки (линия по полу вдоль стен). Если контур недоступен — используется периметр из свойств помещения.
2. Находятся все **двери**, граничащие с этим помещением (с любой стороны: «из комнаты» или «в комнату»).
3. Из полного периметра **вычитается сумма ширин** этих дверей.

**Важно:**

- Вычитаются **все** двери на границе комнаты, в том числе входная с коридора — не только «межкомнатные».
- В некоторых моделях контур уже **обрывается** в местах дверей (двери уже «вырезаны» из периметра). Тогда повторно ширину дверей **не вычитают**, чтобы не получить двойной минус.

---

## 2. Периметр по потолку

**Зачем:** полная длина линии по потолку (карнизы, багеты и т.п.).

**Как считается:**

Берётся **полный периметр** помещения — по контуру отделки или из свойств помещения.

**Отличие от периметра по полу:** двери и проёмы **не вычитаются**. Это всегда полный периметр, без вычетов.

---

## 3. Межкомнатные двери

**Зачем:** сколько полноценных дверей между комнатами квартиры.

**Как считается:**

Просматриваются все двери в модели. Дверь учитывается, если:

- она **с двух сторон** привязана к помещениям квартиры (есть «комната откуда» и «комната куда»);
- это **не проём** — элементы, в названии которых есть слово «проём» / «проем», не считаются дверями.

**Распределение:** одна дверь между гостиной и спальней даёт **+1** и в гостиную, и в спальню.

Входная дверь с улицы или коридора **не попадает** в этот счётчик: с одной стороны обычно нет помещения квартиры.

---

## 4. Двустворчатые двери

**Зачем:** отдельный показатель для гостиной — наличие широких / двустворчатых дверей.

**Где показывается:** только у помещения **«Гостиная»**.

**Как определяется «двустворчатая»:**

- ширина двери **больше 1 метра**, или
- в названии типа двери есть признаки двустворчатости («дв.», «двуств», «2-ств» и т.п.).

Дальше действуют те же правила, что и для межкомнатных дверей: только между комнатами квартиры, без проёмов. Счётчик также увеличивается в **обеих** смежных комнатах, но в итоговой таблице значение видно **только у гостиной**.

---

## 5. Напольная плитка

**Зачем:** площадь плитки в прихожей и на кухне.

**Где показывается:** только **прихожая** и **кухня**.

**Как считается:**

1. В модели ищутся **элементы пола**, у которых в параметре «Модель» указано **«Напольная плитка»** (на самом поле или на его типе).
2. Каждый такой пол привязывается к помещению — по точке внутри комнаты.
3. Площади всех подходящих полов в комнате **складываются**.

Площадь берётся из вычисленной площади элемента или, если её нет, из параметра «ERBO_Площадь».

---

## 6. Фартук на кухне

**Зачем:** общая площадь кухонного фартука.

**Где показывается:** только **кухня**. Значение **одно на всю квартиру** — у всех строк «Кухня» будет одинаковое число.

**Как считается (по приоритету):**

**Вариант А — из ведомости**  
Если в проекте есть спецификация «Спецификация фартука кухни», берётся **сумма площадей** из неё.

**Вариант Б — из стен модели**  
Если ведомости нет: суммируются площади **стен**, у которых в параметре «ERBO_Помещения» указана **«Кухня»** (на стене или на типе стены). Площадь каждой стены — из «ERBO_Площадь».

---

## 7. Площадь стен минус проёмы

**Зачем:** площадь отделки стен (обои, покраска и т.п.) **за вычетом** дверей, проёмов и окон.

**Как считается:**

1. **Периметр** помещения (из свойств комнаты).
2. **Высота потолка** — определяется по высоте стен вдоль контура комнаты; если не получилось — по уровням помещения или его высоте.
3. **Брутто-площадь** = периметр × высота.
4. Из неё **вычитаются площади проёмов** в этой комнате.

**Проёмы — двери:**  
Площадь каждой двери (из «ERBO_Площадь» или ширина × высота) **вычитается в обеих** смежных комнатах, между которыми стоит дверь.

**Проёмы — окна:**  
Площадь окна вычитается **только в одной** комнате. Комната определяется так:

- сначала по параметру «ERBO_Помещения» на окне;
- если не задан — по тому, с какой стороны окна находится внутреннее пространство комнаты (не по общей стене между двумя комнатами, чтобы окно на стене «гостиная — балкон» не попало в обе комнаты).

**Итог:** площадь стен = (периметр × высота) − сумма площадей проёмов. Не может быть отрицательной.

Если периметр или высота неизвестны — замер остаётся пустым.

---

## Кратко: чем отличается от замеров по ведомостям

| | По модели | По ведомостям |
|---|-----------|---------------|
| Источник | геометрия и элементы Revit | таблицы-спецификации в проекте |
| Периметр по полу | контур минус ширины дверей | строки из «Спецификация плинтуса» |
| Площадь стен | периметр × высота − проёмы | сумма из ведомостей по обоям и балкону |
| Фартук | ведомость **или** стены ERBO | только ведомость |
| Периметр молдингов | не считается | есть отдельный замер |

Замеры по модели точнее отражают **фактическую геометрию**, но зависят от корректности фазы, границ помещений и заполнения параметров ERBO. Замеры по ведомостям повторяют **то, что заложено в спецификациях**, но ломаются при переименовании таблиц или колонок.
