# SPEC — Plugin UI Redesign

## Контекст

Текущий flow:

```
ExportSmartRemontRoomsCommand
  → HomeWindow (поиск ремонта)
  → RemontHubWindow (меню функций)
  → дочерние окна (материалы, ДС, замеры…)
```

Глобальное состояние: `ExportRoomsApplication.SelectedRemont`.

---

## 1. Экран «Добро пожаловать» (`HomeWindow`)

### As-is

- Радио: «По ID ремонта» / «По ID заявки»
- Поле + кнопка «Найти»
- Список результатов → выбор → панель «Выбрано» → кнопки «Отмена» / «Продолжить»
- Loader: текст кнопки «Поиск…»
- Ширина: 720 px

### To-be

| # | Требование |
|---|------------|
| 1.1 | **Только поиск по ID ремонта** — убрать radio «По ID заявки» и связанную логику |
| 1.2 | **Красивый поиск** — поле с иконкой/placeholder, inline loader (spinner или progress bar), не менять текст кнопки |
| 1.3 | **Без лишних кнопок внизу** — убрать «Продолжить»; **клик по карточке ремонта** сразу закрывает окно с `DialogResult=true` |
| 1.4 | Оставить «Отмена» и «Выйти» (logout) |
| 1.5 | Debounced search (опционально phase 2): ввод ID → авто-поиск через ~400 ms без кнопки «Найти» |
| 1.6 | Enter в поле — поиск (если кнопка «Найти» убрана на phase 1, Enter обязателен) |
| 1.7 | Один результат — показать карточку; двойной клик не нужен, достаточно одного клика |
| 1.8 | Ширина окна: **Width 900**, MinWidth ~760 (см. DECISIONS #6, `WindowLayoutHelper.HomeDefaultWidth`) |

### Acceptance

- Пользователь вводит `21642` → видит loader → список → **один клик** → hub
- Нет radio «По ID заявки»
- Нет кнопки «Продолжить»

## 2. Hub ремонта (`RemontHubWindow`)

### As-is

- Заголовок «Ремонт» + subtitle (ЖК · кв · пакет)
- Блок info: ID заявки, ID ремонта, клиент, ЖК, квартира, пакет — одинаковый вес
- 8 пунктов меню (в т.ч. «Скоро» stub)
- Ширина: 760 px

### To-be — шапка

| Элемент | Стиль |
|---------|--------|
| **Ремонт** | Крупно, primary: `Ремонт #21642` |
| **Заявка** | Крупно, рядом или строкой ниже: `Заявка #2995745` |
| Название / клиент / ЖК / квартира / пакет | Вторичный блок ниже, меньший шрифт, muted |

### To-be — меню (порядок и названия)

| # | Было | Стало | Действие |
|---|------|-------|----------|
| 1 | Материалы (Revit) | **Синхронизация материалов из Revit** | активен |
| 2 | ДС по изменению квадратуры | **ДС на изменение квадратуры** | активен |
| 3 | Замеры комнат | **Замеры комнат (из спецификаций)** | активен |
| 4 | Замеры по коду | — | **скрыть**, `// TODO: plugin-ui-redesign — вернуть когда готов probe по коду` |
| 5 | Сравнение замеров | — | **скрыть**, `// TODO: plugin-ui-redesign — вернуть сверку spec vs code` |
| 6 | Материалы по комнатам | **ДС на изменение ТК** | активен → `RoomMaterialsWindow` |
| 7 | Изменение параметров типов | — | **скрыть**, `// TODO: plugin-ui-redesign` |
| 8 | ДС по изменению ТК (stub «Скоро») | — | **убрать** (дублирует п.6 после переименования) |

### UX/UI общее

- Ширина окна: **MinWidth 880**, **Width 960** (или 920)
- Больше воздуха между карточками функций
- Единая палитра с HomeWindow: `#1B6FC8`, `#F0F2F5`, card shadow
- Hover / focus states для карточек
- Subtitle каждой функции — короткий, серый, под заголовком
