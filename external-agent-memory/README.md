# external-agent-memory

Память между сессиями AI-агентов и onboarding для новых разработчиков.

## Задачи

| Папка | Описание |
|-------|----------|
| [smart-remont-revit-plugin/](smart-remont-revit-plugin/) | Revit-плагин Smart Remont: auth, экспорт помещений, переименование DLL |

## Как добавить новую задачу

1. Создай подпапку: `external-agent-memory/<slug>/`
2. Минимум: `SESSION_SUMMARY.md`
3. По желанию: `FILE_MAP.md`, `NEXT_STEPS.md`
4. Добавь ссылку в этот README и в корневой [README.md](../README.md)

См. также [AGENTS.md](../AGENTS.md).
