# Задача: доработать главный экран (HomeWindow)

Скопируй этот блок агенту как промпт.

## Промпт для агента

Доработай **главный экран** плагина Revit Smart Remont — окно `HomeWindow` (`SBS/Views/HomeWindow.xaml` + `.xaml.cs`).

Перед началом прочитай:
- [AGENTS.md](../../AGENTS.md)
- [FILE_MAP.md](FILE_MAP.md)
- Текущие файлы: `HomeWindow`, `RemontService`, `AuthService`, `ExportSmartRemontRoomsWindow.xaml` (стили Card/кнопок — для единообразия)

### Контекст

Окно показывается **после логина**, **до** `ExportSmartRemontRoomsWindow`:

```
AuthLoginWindow → HomeWindow → ExportSmartRemontRoomsWindow
```

Точка входа: `ExportSmartRemontRoomsCommand` → `new HomeWindow().ShowDialog()`.

Сейчас экран компактный (460×320): приветствие, обычный `ComboBox` с мок-ремонтами из `RemontService.GetMockRemonts()`, кнопки «Отмена» / «Продолжить».

### Требования к UI/UX

#### 1. Более «расширенный» главный экран

- Увеличь окно (ориентир: ширина ~560–640, высота ~480–560), можно `SizeToContent="Height"` или фиксированный размер с запасом под контент.
- Визуально выровняй с остальными окнами плагина: фон `#F5F5F5`, белая карточка, отступы, стиль как в `ExportSmartRemontRoomsWindow` (секции, подписи).
- Структура экрана:
  - **Шапка:** логотип/название «Smart Remont»
  - **Приветствие:** `Добро пожаловать, {DisplayName}` — имя из `ExportRoomsApplication.CurrentSession.DisplayName`
  - **Блок выбора ремонта** с поиском (см. ниже)
  - **Нижняя панель действий** — кнопки

#### 2. Кнопка «Выйти»

- Добавь кнопку **«Выйти»** (logout).
- По клику:
  - вызвать `AuthService.Logout()` (очищает `auth.session.json`, `CurrentSession`, `SelectedRemont`);
  - закрыть `HomeWindow` с `DialogResult = false` (или отдельный флаг — главное, чтобы не открывался экспорт);
  - опционально: показать снова `AuthLoginWindow` — **не обязательно**, достаточно выхода на Revit.
- Размести «Выйти» заметно (например слева внизу или в шапке справа), не путать с «Отмена».

#### 3. Поиск в селекте ремонтов

- Над списком ремонтов — **поле поиска** (`TextBox` с placeholder «Поиск ремонта…»).
- Фильтрация по `RemontOption.Name` без учёта регистра, по подстроке.
- Источник данных пока мок: `RemontService.GetMockRemonts()` — фильтруй в code-behind или через `ICollectionView` / `CollectionViewSource`.
- Если ничего не найдено — текст «Ремонты не найдены», кнопка продолжения disabled.
- Расширь мок до **8–12** записей в `RemontService`, чтобы поиск было что проверять.

#### 4. Двухшаговый выбор: сначала выбрать, потом продолжить

Сейчас «Продолжить» сразу открывает экспорт. Нужен явный UX:

**Вариант A (рекомендуется):**

1. Пользователь выбирает ремонт в списке (ListBox / DataGrid / ComboBox с фильтром).
2. Показывается карточка/строка **«Выбрано: {название}»**.
3. Кнопка **«Выбрать»** (или «Подтвердить выбор») — фиксирует выбор в `ExportRoomsApplication.SelectedRemont`, но **ещё не закрывает** окно.
4. Кнопка **«Продолжить»** — активна **только после** подтверждённого выбора; закрывает окно с `DialogResult = true` и открывает экспорт (как сейчас).

**Вариант B (проще):**

- Одна кнопка **«Продолжить»**, disabled пока ремонт не выбран в списке; при выборе строки — enabled.

Выбери A, если не указано иное — он лучше соответствует формулировке «после выбора кнопка продолжить или выбрать».

#### 5. Прочие кнопки

| Кнопка | Поведение |
|--------|-----------|
| **Выйти** | Logout + закрыть без экспорта |
| **Отмена** | Закрыть без смены ремонта / без экспорта (`DialogResult = false`) |
| **Выбрать** | Сохранить `SelectedRemont`, показать подтверждение на экране |
| **Продолжить** | Только если ремонт выбран → `DialogResult = true`, Close |

### Технические ограничения

- Namespace: `SmartRemont.ExportRooms.*`
- Не ломать цепочку в `ExportSmartRemontRoomsCommand.cs`
- Сборка: `dotnet build SBS.sln -c Release` — без ошибок
- Минимальный diff: правки в основном `HomeWindow`, `RemontService`; не трогать legacy
- WPF, .NET 8, Revit 2025 add-in

### Критерии приёмки

- [ ] Окно визуально шире/просторнее, читаемые секции
- [ ] «Добро пожаловать, {Имя}» на месте
- [ ] Поиск фильтрует список ремонтов в реальном времени
- [ ] «Выйти» разлогинивает и не открывает экспорт
- [ ] Нельзя «Продолжить» без выбранного ремонта
- [ ] Есть явный шаг выбора (кнопка «Выбрать» или аналог) + «Продолжить»
- [ ] `ExportRoomsApplication.SelectedRemont` заполнен перед экспортом

### После выполнения

Кратко опиши изменения в ответе пользователю и при необходимости обнови `FILE_MAP.md` (секция Views).
