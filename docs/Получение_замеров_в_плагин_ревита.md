Итоговый контракт — два endpoint'а, один и тот же payload в `data` / `header`.

Авторизация: `Authorization: Bearer <JWT>`  

---

## Рекомендуемый для Revit-плагина (по `remont_id`)

GET /common/ds/room-change/read/?remont_id={remont_id}

Пример:

GET https://myspace-api.smartremont.kz/common/ds/room-change/read/?remont_id=12345

|Параметр|Где|Обязательный|Тип|
|---|---|---|---|
|`remont_id`|query|да|integer > 0|

---

## Альтернатива (по `client_request_id`)

GET /client_request/{client_request_id}/ds/room-change/read/

|Параметр|Где|Обязательный|
|---|---|---|
|`client_request_id`|path|да|

---

### Поля ответа

|Поле|Есть в `/common/...`|Есть в `/client_request/...`|Смысл|
|---|---|---|---|
|`remont_id`|да|нет|переданный `remont_id`|
|`client_request_id`|да|нет|заявка по ремонту|
|`ds_id`|да|да|ID ДС ROOM_CHANGE|
|`data`|да|да|тело как у `GET .../ds/{ds_id}/`|
|`header`|да|да|заголовок ДС (`get_ds`)|

`data` внутри — тот же контракт, что у старого:

GET /client_request/2995240/ds/42593/

- `data.data` — комнаты ДС
- `data.sum` — суммы
- `data.wall_height` — высота потолка
- `data.ds_info` — метаданные ДС
- `header` — дублирует заголовок ДС (как в `get_info`)

`action_code`: `EDITED` | `ADDED` | `DELETED`

---

## Если ДС нет или ремонт не найден

Не ошибка, а пустой ответ:

```json
{
  "status": true,
  "error": null,
  "remont_id": 12345,
  "client_request_id": null,
  "ds_id": null,
  "data": null,
  "header": null
}
```

(для `/client_request/.../room-change/read/` — без `remont_id` / `client_request_id` в корне, только `ds_id`, `data`, `header` = `null`)

---

## Ошибки

| Ситуация                         | HTTP    | Пример                                         |
| -------------------------------- | ------- | ---------------------------------------------- |
| Нет токена / нет права           | 401/403 | —                                              |
| Нет `remont_id` в query          | 400     | `Field 'remont_id' is required`                |
| >1 ROOM_CHANGE на заявке (редко) | 400/500 | из SP `get_ds_room_change_from_client_request` |
